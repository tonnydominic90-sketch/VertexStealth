The basics

What is an antidetect browser?

An antidetect browser (also written anti-detect) lets you control the details a website can read about your browser, such as user agent, language, timezone, WebRTC behavior and graphics information, separately for each profile, while keeping each profile's cookies and storage apart.

VertexStealth does this by launching the Chrome or Firefox you already have installed with its own profile folder and settings. It is a profile manager and a fingerprint control panel, not a promise of invisibility: websites use many signals and their own rules.

Separation by design

Your regular browser stays separate.

VertexStealth launches each managed profile with its own browser data location. That means a profile's cookies and local storage aren't simply another tab in your everyday Chrome or Firefox session.

  • ✓Dedicated Chrome user-data directory or Firefox profile folder for each managed profile.
  • ✓Profile configuration and session storage managed inside the VertexStealth app data directory.
  • ✓Separate launch configuration, including proxy settings where configured.
  • ✓Persistent process tracking to help reconcile browser profiles after an app restart.
